# LMS Frontend React App

LMS frontend built using react.

### Dependencies used

- React Router
- Tailwind CSS
- Axios
- Tanstack
    - React Query
    - React Table


### Core Features By Users

- Student
    - Register
    - View all courses & Enroll Courses
    - Enroll for Courses
    - Access Course Material
    - Submit ASsignments
- Teacher
    - Create courses
    - View all courses & Created Courses
    - Add course material
    - Create new assignments
- Admin
    - Data & Records Dashboard
    - User Management
        - Add, update, delete users
        - Update user roles
    - Resourse Management
